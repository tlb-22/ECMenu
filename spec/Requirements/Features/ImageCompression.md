# 压缩图片

## 菜单与输入

菜单名称为 `Compress Images` / `压缩图片`。它只在 Finder 的项目上下文中显示，并同时满足以下条件：

- 至少选中一个对象。
- 所有选中对象都是普通文件。
- 每个文件的类型都属于当前系统支持的图片输入类型。

选择集合中包含文件夹、PDF、类型无法识别的文件或系统不支持的图片时，整条菜单隐藏。目录空白处和侧边栏上下文不显示该菜单。

单选和多选使用相同行为。多图像容器只输出一张 JPG：使用容器的主图像；没有独立主图像语义时使用第一帧，GIF 因而使用第一帧。

## 设置窗口

点击菜单后由主应用显示一个设置窗口：

- 设置使用独立窗口，允许关闭和最小化，但不允许调整大小。
- 设置窗口是非模态的，不阻塞其他右键命令。
- 每次压缩请求独立冻结点击时的图片集合并显示自己的设置窗口。多个压缩窗口可以同时存在，确认或取消其中一个窗口只影响对应批次。
- 窗口提供 Target Width / 目标宽度和 JPG Quality / JPG 质量两项设置。
- 目标宽度使用数字输入框，以像素为单位，默认值为 `1440`。
- 目标宽度只接受有效范围内的正整数。编辑时可以暂时清空字段；字母、空格、小数点、正负号、零以及超出整数范围的数字在输入或粘贴时立即拒绝。
- JPG 质量使用滑动条和当前值，范围为 `0...10` 的整数，步长 `1`，默认值为 `8`。
- 输入不合法时显示本地化错误信息；用户可以选择 Compress / 压缩或 Cancel / 取消。

确认后持久化两个设置，下一次打开时恢复最后一次确认的值；取消或关闭窗口都不修改设置，也不执行转换。窗口最小化不改变当前输入。

质量等级线性映射到编码质量，即界面值除以 `10`。`0` 表示最大压缩，`10` 表示最高质量。

## 进度与取消

用户确认设置后，压缩批次开始报告以图片为单位的确定进度；设置窗口等待期间不产生进度任务。每张图片无论成功或失败，只要已经到达终态，已处理数量就增加一。

任务名称与压缩命令使用同一份本地化名称，进度文本表示已处理图片数与图片总数。窗口、并发任务和延迟显示行为见[命令进度](../CommandProgress.md)。

点击取消只登记取消意图。当前图片完整到达成功或失败终态后停止处理剩余图片，不中断单项编码或文件写入。取消后保留并选择已经完整生成的图片；已经产生的错误继续遵守批量错误反馈规则。

## 缩放与编码

- 输出格式固定为 JPG，扩展名统一为 `.jpg`。
- 根据应用视觉方向后的宽度等比例缩放，高度由原始宽高比计算。
- 原始宽度大于目标宽度时缩小到指定宽度；原始宽度不超过目标宽度时不放大，但仍重新编码为 JPG。
- 缩放使用系统高质量插值。
- 透明区域合成到白色背景。
- 输出保持正确视觉方向，不保留源文件的 EXIF、GPS、XMP、相机信息或容器中的其他帧。
- 源文件始终保留，不移动、不修改、不删除。

## 输出名称、顺序与时间

输出写入每个源文件的同级目录，首选名称为源文件基础名加 `.jpg`。不覆盖任何已有文件；发生冲突时依次使用：

```text
photo.jpg
photo_copy.jpg
photo_copy2.jpg
photo_copy3.jpg
```

如果首选名称本身已经以 `_copy` 或 `_copy` 加数字结尾，后续候选延续该序号，不生成重复的 `_copy_copy`。如果数字已经无法继续递增，则保留完整首选基础名，并以它为新的基础依次追加 `_copy`、`_copy2`。例如 `photo_copy9223372036854775807.jpg` 冲突后的候选为 `photo_copy9223372036854775807_copy.jpg`。

多选输入按 Finder 风格的本地化文件名顺序处理。确认执行时取得统一基准时间；排序后的第一个成功输出使用基准时间，后续项目按照输入序号每项递增一秒。输出文件的创建时间和修改时间设置为同一对应时间；某项转换失败不会改变其他项目预定的时间位置。

转换结束后，成功输出全部保留并由 Finder 自动选中。

## 失败行为

- 源图片没有读取权限或其所在目录不可写时，整个批次结束后按[通用错误反馈](../CommandBehavior.md#错误反馈)显示一次本地化的汇总弹窗。正文引用受影响图片的名称或数量，并分别说明图片无法读取或其所在文件夹不可写；已经产生其他输出时明确表达部分成功。
- JPG 已生成但时间属性写入失败时，在同一弹窗中另起一行，以当前语言说明对应文件的时间属性写入失败；同时存在其他成功图片时明确表达部分成功。
- 文件在执行前失效、内容损坏、解码或编码失败及其他罕见错误，使用[通用非弹窗反馈](../CommandBehavior.md#错误反馈)；同一批次还包含弹窗错误时也遵循该页的统一汇总规则。

对应技术设计见[压缩图片](../../Technical/Features/ImageCompression.md)。
